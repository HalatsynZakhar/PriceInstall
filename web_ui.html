Ціни Хорошоп

Безпечне масове оновлення поточних, старих і оптових цін.

Доступ до API

Вкажіть логін і пароль API або чинний токен. Дані використовуються лише для поточної операції.

Встановити одну ціну

Підходить для швидкої зміни одного товару. Для Опт 1-5 можна задати свій поріг; для Опт 4-5 він обов'язковий. Щоб видалити РРЦ або опт, введіть «Видалити» замість суми.

Масова зміна через Excel

Один рядок — один товар. Порожня клітинка нічого не змінює, а для видалення РРЦ або опта напишіть «Видалити».

Перетягніть Excel-файл сюди або натисніть для виборуПідтримуються .xlsx та .xlsm. Колонки: артикул, поточна ціна, РРЦ, перенесення між цінами, Опт 1-5 та їх пороги.
Завантажити шаблон
1. ЗаповнітьОдин рядок для товару. За потреби додайте нову поточну ціну, РРЦ та опт.
2. ПеревіртеСтатус «Готово до операції» означає, що рядок знайдений і безпечний для імпорту.
3. ЗастосуйтеМожна перенести поточну ціну в РРЦ або РРЦ у поточну ціну. Опт не знижується від акції.

Результат останньої операції
